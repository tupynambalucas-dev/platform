# Kubernetes Infrastructure Plugin (`@tupynambalucas-dev/plugin-k8s`)

Native agent plugin providing GitOps documentation auditing, Diataxis compliance, and Kubernetes manifest architecture skills.

## Skills Exposed

- **`k8s-docs-auditor`**: Audits Kubernetes infrastructure documentation against Diataxis standards and manifest realities.
- **`k8s-docs-architect`**: Authors and maintains technical GitOps guides, tutorials, references, and architectural explanations.
